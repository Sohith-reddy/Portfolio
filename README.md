## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/Sohith-reddy/portfolio.git

# Install dependencies
cd portfolio
npm install

# Create .env.local file
copy .env.example .env.local

# Start development server
npm run dev
```
